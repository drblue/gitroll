# Course registration

Gitroll connects students on a class roster to their GitHub accounts and helps them get access to their Classroom 50 assignments.

## Language

**Class**:
A group of students with a shared roster and a GitHub student team. A class can have multiple Classroom 50 assignments.

**Roster entry**:
A student’s place on a class roster, shown by name and available for registration until a GitHub account is linked to it.

**Registration link**:
The shared link a teacher gives students to open self-registration for a class.

**Account link**:
The association between one roster entry and one GitHub account within a class. The same association applies to every assignment in the class.

**Organization invitation**:
A GitHub invitation for an account to join the organization, with the class’s student team included when applicable. The account holder must accept it on GitHub.

**Student team**:
The Classroom 50 GitHub team whose members are enrolled in the class.

**Class membership**:
An active membership in the class's student team. A student can be a class member without an account link on Gitroll's roster.

**Access revocation**:
A teacher's decision to withdraw an account's access through the student team of a specific class. The teacher must explicitly restore access before the account can rejoin through Gitroll.

**Assignment**:
An individual piece of coursework in Classroom 50 associated with a class.

**Assignment link**:
The Classroom 50 link students use to accept an assignment.

**Student repository**:
The private GitHub repository Classroom 50 creates from the assignment template after a student accepts the assignment.
