# Register once per class

Students join a class once and can then work on multiple Classroom 50 assignments. Gitroll uses one shared registration link, one roster, and one Classroom 50 student team per class. Each account link belongs to the class and applies to all current and future assignments in that class.

## Consequences

- After GitHub sign-in, a student with verified active membership in the class's student team skips name selection and proceeds to the class's assignments, including when they joined outside Gitroll. Gitroll does not guess a roster entry for them. [Classroom 50 enrollment](https://github.com/foundation50/classroom50/wiki/How-Classroom-50-Works#from-invitation-to-enrollment)
- A signed-in student with a valid registration link can see available roster entries. Confirming a choice claims the entry immediately, with at most one entry per GitHub account per class. The teacher gives students distinct display names when two roster entries would otherwise look identical.
- The teacher can close registration or replace the shared link. Students who have already registered can sign in again to resume their flow.
- GitHub account IDs identify students and approved teacher accounts. Resetting an account link or removing a roster entry is separate from removing access through the student team. Organization membership and direct access to student repositories are managed in GitHub.
